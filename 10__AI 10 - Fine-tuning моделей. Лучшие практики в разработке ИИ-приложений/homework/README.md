# Домашнее задание 10 — Fine-tuning классификатора отзывов

**Цель:** выбрать небольшой датасет, очистить и разбить его на выборки, **дообучить предварительно обученную модель** и оценить качество на ранее не виденных примерах.

## 1. Датасет и подготовка

Использован реальный общедоступный датасет **UCI Sentiment Labelled Sentences**, поднабор **Amazon product reviews** (английский язык, 0 — негативный, 1 — позитивный отзыв).

- Источник: https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences
- Исходный архив: https://archive.ics.uci.edu/static/public/331/sentiment+labelled+sentences.zip
- Публикация: Kotzias et al., *From Group to Individual Labels using Deep Features*, KDD 2015 (атрибуция авторов датасета).
- **prepare_data.py**: декодирование HTML-сущностей, нормализация Unicode и пробелов, удаление HTML-тегов, удаление дублей без учёта регистра. Конфликтующие метки считаются ошибкой.
- Подготовленные данные: **data/reviews.tsv**, происхождение и контрольные суммы: **data/provenance.json**.

| Этап | Число примеров |
|---|---:|
| Исходные записи | 1 000 |
| Удалённые дубликаты | 13 |
| После очистки | **987** |
| Train (обучение) | 690 |
| Validation (выбор лучшей эпохи) | 147 |
| Test (оценка обобщения) | 150 |

Разделение **70% / 15% / 15%**, стратифицированное по классу (с округлением), seed = 42. Оно выполняется *после* удаления дублей. Код проверяет, что одинаковые тексты не попадают в разные выборки.

## 2. Модель и fine-tuning

- Модель: [prajjwal1/bert-tiny](https://huggingface.co/prajjwal1/bert-tiny) — небольшой предварительно обученный BERT.
- Задача: **бинарная классификация тональности текста**.
- Обучение: AutoModelForSequenceClassification и **Hugging Face Trainer**. 9 эпох, learning rate = 0.0001, batch size = 16, максимум 96 токенов.
- Выбор лучшей эпохи по F1 положительного класса на validation: **8-я эпоха**.
- Оборудование: **Mac M1, Apple Metal MPS**.
- Метрики: Accuracy, Precision, Recall, F1 и confusion matrix.

Выполнено **полное дообучение предварительно обученной модели BERT-tiny**: параметры модели обновлялись на обучающей выборке, а лучшая эпоха определялась на валидационной.

Метрики, параметры, версии библиотек и история обучения: **results/metrics.json**. Первый эксперимент: **results/experiment_3epochs.json**. Примеры тестовых предсказаний: **results/test_examples.tsv**.

**Ограничения:** небольшой учебный датасет одного источника и один seed; качество нельзя автоматически переносить на другие языки и домены. Test не использовался при обновлении весов или выборе лучшей эпохи. Однако test уже был просмотрен после первого трёхэпохового запуска, до второго эксперимента. Такой итеративный подбор может приводить к оптимистичной оценке. Для независимой окончательной проверки нужна ещё одна полностью нетронутая выборка.

## 4. Воспроизведение

Требуется **Python 3.10** и зависимости из **requirements.txt**; для первого скачивания bert-tiny необходим интернет. Установка в новую виртуальную среду:

    python3.10 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python -m unittest -v test_pipeline.py
    python train.py

Для повторной загрузки и очистки датасета из UCI:

    python prepare_data.py

Первый короткий эксперимент можно повторить командой:

    AI10_EPOCHS=3 AI10_LR=5e-5 python train.py

Команда **python train.py** запускает итоговую конфигурацию (9 эпох, learning rate = 0.0001), сохраняет метрики в **results/metrics.json**, а веса обученной модели — в **artifacts/**.
