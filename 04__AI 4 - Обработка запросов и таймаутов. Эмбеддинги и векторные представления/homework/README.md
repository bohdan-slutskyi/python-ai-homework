# Семантический поиск по текстам

Скрипт `f_demo_google.py` продолжает пример преподавателя: индексирует 40
предложений, принимает произвольный текстовый запрос, находит четыре наиболее
похожие фразы и объединяет их в один текст.

## Защита API-запросов

- Пакетная индексация выполняется одним запросом; поиск — ещё одним.
- Между запросами выдерживается интервал не менее секунды.
- Таймаут одного HTTP-запроса — 20 секунд.
- `tenacity` повторяет временные сетевые ошибки, HTTP 429 и 5xx не более трёх
  раз с экспоненциальной случайной задержкой. Ошибки ключа и некорректного
  запроса не повторяются.
- При HTTP 429/5xx Google рекомендует учитывать действующие лимиты проекта и
  повторять после паузы; точные лимиты меняются в зависимости от модели и
  уровня проекта.

## Настройка и запуск

Нужен Python 3.10+ и `uv`. Окружение проекта создаётся в этой папке и не меняет
глобальные пакеты:

```bash
cd "/Users/core/Dev/Python_for_AI_Morning_2025_PD/04__AI 4 - Обработка запросов и таймаутов. Эмбеддинги и векторные представления/homework"
uv sync
uv run python f_demo_google.py
```

Ключ `GEMINI_API_KEY` загружается из локального `.env` проекта AI 3. Копия ключа
в папке AI 4 не создаётся, значение не печатается и в снимок не попадает.

## Почему пример обновлён

В файле преподавателя использовались `google.generativeai` и
`gemini-embedding-001`. В решении применены официальный поддерживаемый SDK
`google-genai` и `gemini-embedding-2`. FAISS заменён на NumPy: это сохраняет
ранжирование по cosine similarity и не требует устанавливать второй набор
бинарных библиотек в глобальную среду.

Документация Google:

- [Google GenAI SDK для Python](https://ai.google.dev/gemini-api/docs/libraries)
- [Модели и форматы Gemini Embeddings](https://ai.google.dev/gemini-api/docs/embeddings)
- [Лимиты Gemini API](https://ai.google.dev/gemini-api/docs/rate-limits)

## Проверка

Скрипт был запущен через `uv run python f_demo_google.py` с тестовым запросом.

вывела их объединённый текст. API-ключ и его значение в проект не добавляются.
