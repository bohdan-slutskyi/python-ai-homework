# Распознавание речи и идея мультимодального приложения

## Эксперимент с Whisper

Локально запустил многоязычную модель Whisper Medium через `whisper.cpp` на CPU. Для обоих источников использовал моно WAV с частотой 16 кГц и автоматическим определением языка.

### Звуковая дорожка учебного видео

Источник — [Functions, Harvard CS50P](https://youtu.be/lGS6O47debI?t=58), фрагмент 00:58–01:19. Дорожку извлёк из [MP4 курса](https://cdn.cs50.net/python/2023/x/shorts/functions/functions-360p.mp4). Whisper определил английский язык (`en`).

```text
And one function built into Python is called the print function where the print function takes some text as input and
produces as output this text in my terminal down below
So I'll type print here and I'll follow it with parentheses just like this and I'll type hello
world like that
```

По [официальным субтитрам](https://cdn.cs50.net/python/2023/x/shorts/functions/lang/en/functions.srt) ключевые слова переданы верно, включая `print`, `parentheses` и `Hello, world!`. Whisper почти не поставил знаков препинания и разбил «hello world» переносом строки.

### Синтезированное аудиосообщение

Второй источник — голос Milena из macOS, 8,66 секунды. Исходная фраза: «В Питоне функции помогают разбить программу на небольшие части. Функция получает данные, выполняет действие и может вернуть результат». Whisper определил русский язык (`ru`).

```text
В Python функции помогают разбить программу на небольшие
части.
Функция получает данные, выполняет действие и может
вернуть результат.
```

Оба предложения переданы полностью. Модель записала произнесённое «Питоне» как `Python`. В обоих примерах смысл сохранился. Источники различаются одновременно языком и типом голоса, поэтому по этому опыту нельзя отдельно оценить влияние каждого фактора.

## Как повторить

Команды выполняются в рабочей папке для аудиофайлов. Для второго примера нужен системный голос Milena.

```bash
ffmpeg -ss 58 -i "$HOME/Downloads/functions-360p.mp4" \
  -t 21 -vn -ac 1 -ar 16000 video.wav

say -v Milena -o speech.aiff \
  'В Питоне функции помогают разбить программу на небольшие части. Функция получает данные, выполняет действие и может вернуть результат.'
ffmpeg -i speech.aiff -ac 1 -ar 16000 speech.wav

model="$HOME/.local/share/whisper-cpp/models/ggml-medium.bin"
for sample in video speech; do
  whisper-cli -m "$model" -ng -l auto -f "$sample.wav" -otxt -of "$sample"
done
```

## Идея приложения — поиск примеров кода в видеоуроках

Ученик спрашивает: «Где преподаватель впервые показывает вызов `print()`?». Whisper преобразует объяснение в текст с таймкодами. Модель для изображений читает код на кадрах экрана. Приложение сопоставляет кадры с речью по времени и возвращает ссылку на момент, когда преподаватель начинает набирать вызов, и короткий фрагмент кода.

Речь помогает понять, что преподаватель объясняет, а кадр показывает точный синтаксис, включая кавычки и скобки. Если кадр нечитаемый, приложение может вернуть таймкод и отметить, что синтаксис по видео не удалось проверить.
