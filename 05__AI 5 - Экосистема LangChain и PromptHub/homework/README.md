# Пересказ веб-страницы

`WebBaseLoader` получает текст страницы в виде списка `Document`.
`create_stuff_documents_chain` подставляет документы в `{context}` шаблона,
передаёт сформированный запрос модели и возвращает строку пересказа.
Загрузка страницы происходит до вызова модели. История диалога не сохраняется.

Требуется Python 3.10. Зависимости зафиксированы в `requirements.txt`.
В отдельном виртуальном окружении установите их командой:

```bash
python -m pip install -r requirements.txt
```

Из папки с этим README проверка цепочки без сети и API:

```bash
python summarize_url.py --self-check
```

Запуск с публичной короткой страницей и ключом в переменной окружения:

```bash
python summarize_url.py https://example.com
```

Можно передать `--env-file /путь/к/локальному/.env`. Файл ключа не копируется,
его значение не выводится. Параметр `--model` позволяет указать доступную модель.
Текст выбранной страницы отправляется в Gemini API; загрузка страницы и
вызов модели требуют сети. Ответ модели может содержать ошибки и требует чтения.

Загрузка ограничена таймаутом 20 секунд. Пустой текст и страницы длиннее
40 000 символов отклоняются до запроса к модели. Это учебное ограничение,
а не подсчёт токенов. При сетевой ошибке выполнение завершается с ошибкой.

`--self-check` использует тестовую модель: проверяет соединение компонентов,
но не качество пересказа и не доступность Gemini. Реальный API-запуск выполнен 04.11.2026 на https://example.com
с моделью gemini-3.5-flash-lite. Ответ сохранён в results/example.txt.
Интерфейс PromptHub изучен; три промпта описаны в [prompthub.md](prompthub.md).
Обязательные пункты выполнены. Дополнительная цепочка по файлу не реализована.

Проверенный пересказ передаёт три утверждения исходной страницы: домен
предназначен для примеров документации, разрешение не требуется, использовать
его для тестирования и мониторинга не рекомендуется.
