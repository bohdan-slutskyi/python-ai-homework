# PromptHub: интерфейс и три промпта

Дата изучения: 04.11.2026.

## Интерфейс

После регистрации доступна Library — библиотека собственных проектов, где
предлагаются создание проекта и группы. В Discover находятся публичные промпты
сообщества: есть поиск, категории, сортировка, просмотр групп и пользователей.
В карточке промпта доступны его текст, автор, Overview и History, текущая
ревизия, сведения о модели и категории. Кнопки Copy и Add to Library позволяют
скопировать текст или добавить промпт в свою библиотеку. Наличие этих кнопок
проверено визуально; добавление проектов и запуск моделей не выполнялись.
В навигации также присутствуют Templates, Database, Evaluations, Batches и
Chains Beta; работа этих разделов отдельно не проверялась.

## 1. Chain of Density

[Карточка промпта](https://app.prompthub.us/prompthub/chain-of-density).
Просмотрена Revision 2, `593ea2d3`.

**Назначение:** получить краткое изложение статьи с высокой плотностью полезной
информации. На вход передаётся текст статьи в переменную `Article_Content`.

**Принцип:** пять раз повторить поиск 1–3 важных сущностей, пропущенных в
предыдущем пересказе, и переписать пересказ с их включением. Длина должна
оставаться одинаковой, ранее включённые сущности сохраняются. Результат
запрашивается как JSON со списком из пяти объектов с полями `Missing_Entities`
и `Denser_Summary`.

**Почему интересен:** позволяет сравнить несколько вариантов пересказа одной
статьи и увидеть, какую информацию можно добавить без увеличения объёма.
Подходит для конспектов и кратких обзоров документов.

**Ограничение:** одинаковую длину, корректность JSON и соответствие всех фактов
статье нужно проверять. Само увеличение плотности не гарантирует читаемости.

## 2. Cognitive Verifier

[Карточка промпта](https://app.prompthub.us/prompthub/cognitive-verifier).
Просмотрена Revision 1, `52433772`.

**Назначение:** уточнить исходный вопрос до подготовки окончательного ответа.
Входные данные — вопрос пользователя, затем ответы на три уточнения.

**Принцип:** модель формулирует три дополнительных вопроса, получает ответы
пользователя и объединяет их при ответе на первоначальный вопрос. Например,
при выборе языка для веб-разработки уточняются опыт, интерес к frontend или
backend и необходимые возможности.

**Почему интересен:** помогает превратить слишком общий запрос в конкретную
задачу. Полезен при обсуждении требований к учебному проекту и выборе подхода.

**Ограничение:** требует участия пользователя. Три вопроса могут оказаться
избыточными для простой задачи или недостаточными для сложной. Несмотря на
название, промпт не проверяет факты по внешним источникам.

## 3. Semantic Alternative Enhancer

[Карточка промпта](https://app.prompthub.us/prompthub/semantic-alternative-enhancer).
Просмотрена Revision 5, `6a59505c`.

**Назначение:** улучшить формулировку длинного промпта, сохранив исходный смысл.
Входные данные — исходный запрос в переменной `prompt`.

**Принцип:** разделить запрос на предложения, переформулировать каждое с учётом
контекста для ясности, краткости и уместности, затем собрать новый запрос.
На выходе должен быть только улучшенный промпт.

**Почему интересен:** помогает убрать повторы и неоднозначные формулировки
из технического задания или запроса на анализ текста.

**Ограничение:** при сокращении могут потеряться существенные условия.
Нужно сравнить исходный и новый запрос, особенно обязательные ограничения,
формат результата и исключения.

## Вывод

Три промпта решают разные задачи: уплотнение пересказа, уточнение требований
и редактирование запроса. Для цепочки пересказа веб-страницы наиболее близок
Chain of Density. Это описание прочитанных шаблонов, а не результаты их
экспериментального сравнения: запросы к моделям через PromptHub не выполнялись.
