## 3. Объяснение list и tuple

Сессия: `ses_e81469e7dffea9hACkK5V4PNyi`. Начало: 2026-10-27T19:57:20.902000+01:00. Завершение: 2026-10-27T19:57:24.957000+01:00.

### Полный отправленный запрос

```text
Ответь только текстом на задание ниже. Не используй инструменты, не читай и не изменяй файлы, не выполняй команды.

Объясни новичку разницу между list и tuple в Python. Дай три коротких
нумерованных пункта: изменение содержимого, запись в коде и типичное применение.
Затем приведи один исполняемый пример не длиннее шести строк с комментариями
на русском. Не утверждай, что внутри tuple вообще ничего не может меняться:
одним отдельным предложением поясни случай со вложенным списком.
В конце задай один вопрос для самопроверки и отдельно напиши ответ.
```

### Фактический ответ

1. **Изменение содержимого**: список (`list`) можно менять — добавлять, удалять и заменять элементы; кортеж (`tuple`) после создания неизменяем (нельзя добавить/удалить/заменить элемент).
2. **Запись в коде**: список пишут в квадратных скобках `[1, 2, 3]`, кортеж — в круглых `(1, 2, 3)` (или без скобок через запятую).
3. **Типичное применение**: список — когда набор данных будет меняться; кортеж — для фиксированных записей (координаты, дата, элементы, которые не должны меняться случайно).

Пример (не длиннее 6 строк):

```python
# Создаём список и кортеж
items = [1, 2, 3]          # список — можно менять
point = (10, 20)           # кортеж — фиксированный набор
items.append(4)            # список изменился: [1, 2, 3, 4]
# point[0] = 5             # ошибка: кортеж неизменяем
print(items, point)        # вывод: [1, 2, 3, 4] (10, 20)
```

Оговорка: если внутри кортежа лежит изменяемый объект (например, список), то сам кортеж нельзя заменить на другой, но его вложенный список можно изменять.

Вопрос для самопроверки: можно ли после создания кортежа `t = (1, [2, 3])` выполнить `t[1].append(4)` — и чем это закончится?

Ответ: да, можно; кортеж остаётся тем же объектом, но его вложенный список станет `[2, 3, 4]`, потому что изменяется список внутри, а не сам кортеж.
