# Домашнее задание 9 — примеры применения RAG

Источник условия: https://lms.itcareerhub.de/mod/assign/view.php?id=15637

## 1. Три задачи, в которых полезен RAG

### Поиск нужного момента в записи видеоурока

**Проблема.** В длинной записи занятия трудно найти момент, когда преподаватель объясняет конкретную тему или впервые показывает нужную строку кода. Обычный поиск по названию видео не помогает, а языковая модель не знает содержание этой записи.

**Как помогает RAG.** Приложение индексирует расшифровку аудио с таймкодами и, если доступны, текст слайдов или распознанный код с кадров. По вопросу ученика оно извлекает подходящие фрагменты и возвращает объяснение со ссылкой на точный момент видео. Например, на запрос «Где впервые показывают вызов print()?», система даёт таймкод, а не придумывает ответ. Здесь RAG применяется к поиску внутри *мультимодальных учебных материалов*, а не просто к справке по документации.

### Поиск причин повторяющихся технических инцидентов

**Проблема.** При новом сбое инженер видит код ошибки и фрагмент журнала событий, но не знает, сталкивалась ли команда с похожей ситуацией ранее. Старые инциденты хранятся в разных отчётах; по одному ключевому слову похожие случаи не всегда находятся.

**Как помогает RAG.** Система извлекает релевантные записи из истории инцидентов, журналов и описаний исправлений. Она может сочетать точный поиск по кодам ошибок (например, BM25) и семантический поиск по описаниям симптомов. Модель составляет список вероятных причин и проверок со ссылками на конкретные инциденты. Решение о применении исправления остаётся за инженером.

### Подбор актуальных грантов для небольшого проекта

**Проблема.** У разных программ поддержки свои критерии: страна, вид деятельности, бюджет, срок приёма заявок и необходимые документы. Условия регулярно меняются. LLM, не обращаясь к текущим источникам, может предложить уже закрытую программу.

**Как помогает RAG.** По параметрам проекта система ищет в официальных описаниях действующих конкурсов и структурированных данных программ. Затем сопоставляет требования с профилем проекта, выделяет спорные условия и показывает ссылки на первоисточники, дату актуальности и срок подачи. Если сведений недостаточно, она не делает вывод о гарантированной возможности участия. Это не просто пересказ текста, а подбор по нескольким меняющимся критериям.

## 2. Реальные продукты и инструменты с поддержкой RAG

### Microsoft Azure AI Search

**Компания:** Microsoft. **Продукт:** Azure AI Search.

Это поисковая платформа, на базе которой можно строить RAG-приложения: индексировать документы, находить подходящие фрагменты при помощи текстового, векторного или гибридного поиска и передавать их языковой модели для формирования ответа. Microsoft также описывает agentic retrieval — поиск с предварительным планированием запросов.

Источник: https://learn.microsoft.com/en-us/azure/search/retrieval-augmented-generation-overview

### Amazon Bedrock Knowledge Bases

**Компания:** Amazon Web Services. **Продукт:** Amazon Bedrock Knowledge Bases.

Сервис помогает подключать корпоративные данные к генеративным AI-приложениям. При вопросе пользователя система ищет релевантную информацию в базе знаний, добавляет её в контекст языковой модели и может включать ссылки на первоисточники.

Источник: https://docs.aws.amazon.com/bedrock/latest/userguide/knowledge-base.html

## Вывод

RAG полезен, когда ответ должен опираться не только на общие знания модели, а на конкретные, проверяемые и обновляемые документы. Главное преимущество — возможность находить актуальные сведения с указанием источника без постоянного fine-tuning. При этом качество зависит от содержимого документов, поиска и контроля доступа.

Проверено по официальной документации продуктов 12 ноября 2026 года.
