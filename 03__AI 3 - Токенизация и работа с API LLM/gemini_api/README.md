# Запрос к Gemini API

Python-приложение отправляет один текстовый запрос в Gemini API и сохраняет
успешный ответ в `results/response.json`. Ключ загружается из `.env` либо
переменной окружения `GEMINI_API_KEY`. Ключ не выводится и не сохраняется
в результатах.

## Подготовка

Требуется Python 3.10 или новее. Команды выполняются из папки проекта:

```bash
python -m pip install -r requirements.txt
cp .env.example .env
```

В `.env` локально заполняется `GEMINI_API_KEY`. Значение `GEMINI_MODEL`
определяет модель. В примере указан `gemini-3.5-flash-lite`; фактический доступ
и квота зависят от проекта Google AI Studio. Подключение платного тарифа
для подготовки этого проекта не требуется.

## Запуск

```bash
python app.py
python app.py --prompt "Объясни, что такое токен, в двух предложениях."
```

Используется REST-метод `generateContent` с ключом в HTTP-заголовке
`x-goog-api-key`. URL и код не содержат ключа. Внешние инструменты модели
не подключаются. Отсутствие ключа, неуспешный HTTP-ответ или пустая генерация
завершают программу с ошибкой; они не выдаются за успешный ответ модели.

## Проверка без обращения к API

```bash
python -m unittest discover -s tests -v
```

Эти проверки подменяют HTTP-запрос и проверяют обработку ответа. Они не
подтверждают доступность Gemini и не заменяют реальный запуск.

## Скриншот результата

После успешного запроса сохраняется настоящий скриншот терминала: команда
запуска, модель и полученный ответ. В кадре не должно быть значения ключа
или содержимого `.env`. Скриншот помещается в `screenshots/`.

Реальный запрос к `gemini-3.5-flash-lite` выполнен успешно; ответ сохранён
в `results/response.json`. Снимок результата из терминала VS Code сохранён
в `screenshots/gemini_response.jpg`.
